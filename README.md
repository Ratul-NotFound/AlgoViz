## 🌟 Overview

**AlgoFlowX** is a dual-mission platform combining **low-level systems programming education** with **tactile, frame-by-frame data structure and algorithm visualizations**:

1. **🎓 C Programming Academy**: 23 complete chapters, 230 interactive quizzes & labs, physical real-life analogies, memory byte visualizers, and a free official Certificate of Completion.
2. **⚡ In-Browser C Virtual Machine & Compiler**: 100% client-side zero-server-load C execution engine ($<10\text{ms}$ execution) with interactive standard input (`scanf()`), memory simulation (`malloc()`, `free()`), and standard libraries.
3. **📊 40+ Interactive DSA Visualizers**: Frame-by-frame execution with synchronized multi-language code tracking (Python, C, C++, Java, JavaScript) and real-time Web Audio API synthesizer.
4. **⚔️ Algorithm Battle Arena**: Side-by-side head-to-head racing between sorting algorithms on identical datasets.

## ✨ Flagship Capabilities

### 1. 🎓 C Programming Academy (23 Chapters & 230 Quizzes)
* **What, Why, Where & How Pedagogy**: Every concept explains why it was created, how computers execute it, and where industry giants (Linux kernel, game engines, embedded microcontrollers) use it today.
* **Hyper-Visual Real-Life Analogies**:
  * 📦 **Variables**: Cardboard shipping box with customs labels, barcode, and physical tokens.
  * 🏦 **Const & Immutability**: Bank vault door with security status indicators.
  * 🔌 **Bitwise ALU**: 8-bit registers with interactive bit toggles and logic gate truth tables.
  * 🎛️ **Conditional Branching**: Railway track junction switch with signal lights.
  * 🏃 **Loops**: Stadium running track with lap counter scoreboard.
  * 🥚 **Arrays**: 10-slot wooden egg carton with contiguous memory addresses.
  * 🚂 **Strings**: Freight train carriages with `\0` null-terminator caboose.
  * 🪆 **Recursion**: Russian nesting dolls unpacking to the solid base case.
  * 🏠 **Pointers & Memory Addresses**: Suburban house numbers with laser pointers and key locks.
  * 📁 **Structs & File I/O**: Leather multi-compartment passport wallet.
  * 🏢 **Stack vs Heap**: Multi-level storage rental facility with automatic stack frames and dynamic heap units.
* **10-Question Chapter Examinations**: 230 total questions with instant feedback, explanations, and coin rewards.
* **Verified Gold Certificate of Completion**: Personalized certificate generation with editable student names, verification credentials, and printable formatting.

### 2. 💻 100% In-Browser C Compiler & Virtual Sandbox
* **Zero Backend Load & Free Hosting Friendly**: Runs 100% in the user's browser runtime with pure JavaScript AST virtual machine simulation ($<35\text{KB}$, $<10\text{ms}$ latency, zero server compute overhead).
* **Zero Device Strain**: Lightweight execution guard with 150,000-step infinite loop protection prevents browser tab freezing.
* **Interactive Standard Input**: Built-in **📥 Custom Input** drawer for testing interactive `scanf()` and `getchar()` programs.
* **Full C Standard Library Emulation**:
  * `<stdio.h>`: `printf()` (with `%d`, `%f`, `%.2f`, `%s`, `%c`, `%x`, `%p`), `scanf()`, `puts()`, `putchar()`, `getchar()`.
  * `<stdlib.h>`: `malloc()`, `free()`, `rand()`, `abs()`, `exit()`.
  * `<string.h>`: `strlen()`, `strcmp()`, `strcpy()`, `strcat()`.
  * `<math.h>`: `sqrt()`, `pow()`, `abs()`, `fabs()`, `floor()`, `ceil()`.
  * Custom functions with arguments, return values, and recursion.

## 🚀 Getting Started

### Prerequisites
* **Node.js** (v18.0.0 or later)
* **npm** (v9.0.0 or later)

### Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ratul-NotFound/AlgoViz.git
   cd AlgoViz
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables (Optional)**:
   ```bash
   cp .env.example .env
   ```
   *(AlgoFlowX includes automatic fallback demo mode if credentials are not configured!)*

4. **Start development server**:
   ```bash
   npm run dev
   ```

5. **Build for production**:
   ```bash
   npm run build
   npm run preview
   ```
