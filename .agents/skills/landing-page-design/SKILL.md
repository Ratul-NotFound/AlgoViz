# Landing Page Design System — AlgoFlowX

## 1. Core Philosophy & Value Proposition
AlgoFlowX combines **Low-Level Code Learning (C/Python Academy)** with **Tactile DSA Visualizers**.
The landing page must immediately communicate both halves of this equation above the fold without clutter.

### Key Rules
- **No Gradients Rule**: All backgrounds, buttons, and borders must use curated solid flat colors (`#10b981`, `#2563eb`, `#111827`, `#f8fafc`).
- **Show, Don’t Just Tell**: Every visitor must be able to interact with a real simulation in under 3 seconds without signing in.
- **Dual-Flagship Architecture**: Give equal, balanced prominence to both the **Interactive Coding Academy** and the **Algorithm Visualizer Studio**.

---

## 2. Page Structure & Visual Hierarchy

```
1. Global Navigation Bar (Slim, responsive, quick mode switcher)
2. Hero Workbench (Dual-Zone: Value Proposition + Live Interactive Sandbox)
3. Dual Flagship Gateway Cards (C Academy Track + DSA Visualizer Arena)
4. Tactile Value Pillars (3-Column: Real Analogies, Step-by-Step, Multi-Language)
5. Platform Directory & Catalog (Segmented Tabs: Visualizers, Curriculums, Growth)
6. Feature Bento Grid (Side-by-side comparison, compiler sandbox, duel arena)
7. Final Call to Action & Developer Footer
```

---

## 3. Hero Workbench Section Design

### Left Column: Value Proposition & CTAs (57% Desktop Width)
- **Eyebrow Pill**: Live activity badge (e.g. `🟢 C Master Academy • 40+ Interactive DSA Visualizers`).
- **H1 Headline**: High contrast, bold (`32px` desktop, `24px` mobile), high legibility.
  - Pattern: `Learn Coding & Master Algorithms Through Tactile Visuals.`
- **Body Lead**: 2-3 lines explaining mental model formation through physical analogies and frame-by-frame tracing.
- **Action Group**:
  - Primary CTA: `🎓 Start Learning C (14 Chapters) →` (`#10b981` solid green).
  - Secondary CTA: `▶ Explore Visualizer` (`#2563eb` solid blue).
  - Tertiary CTA: `⚔️ Battle Arena` (Ghost outline).
- **Highlights Bar**: Fast facts (`100% Free & Open Access`, `140 Chapter Exam Questions`, `In-Browser C Sandbox`).

### Right Column: Live Interactive Sandbox (43% Desktop Width)
- **Live Preview Console**: Embedded interactive simulation with Quick Sort, Bubble Sort, and Binary Search tabs.
- **Metrics Strip**: Real-time Step Counter, Comparisons, Swaps.
- **Playback Controls**: Step Forward, Play/Pause, Reset.

## 5. Spacing & Rhythm (8px Grid Standard)
- Container: `max-width: 1280px; margin: 0 auto;`
- Desktop Padding: `32px 24px 80px; gap: 32px;`
- Tablet Padding: `24px 20px 64px; gap: 24px;`
- Mobile Padding: `16px 12px 52px; gap: 16px;`
