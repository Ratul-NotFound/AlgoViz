## 🌟 Overview

**AlgoFlowX** brings complex computer science concepts to life with **step-by-step frame execution**, **line-by-line synchronized code tracking across 5 languages**, **real-time audio sonification**, and an **Algorithm Duel Arena**.

Whether you are preparing for technical coding interviews or studying for university exams, AlgoFlowX offers intuitive mental models of memory allocation, pointer mutations, graph traversals, and asymptotic complexities.

---

## ✨ Key Features

### 1. 📊 19 Comprehensive DSA Modules
* **Sorting Algorithms**: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort, Heap Sort.
* **Searching Algorithms**: Linear Search, Binary Search.
* **Fundamental Data Structures**: Stack (LIFO Canister), Queue (FIFO Tube), Singly Linked List, Doubly Linked List (Bidirectional Cables), Circular Queue (360° Radial Clock Dial), Binary Heap (Min-Heap Tree), Hash Table (Separate Chaining).
* **Graph Algorithms**: Breadth-First Search (BFS), Depth-First Search (DFS), Dijkstra's Shortest Path Algorithm.
* **Trees & Hierarchies**: Binary Search Tree (BST Insertion, Search, & Traversal).

---

### 2. 💻 Synchronized Multi-Language Code Debugger
* Toggle seamlessly between **Python**, **C**, **C++**, **Java**, and **JavaScript**.
* Line-by-line active code highlighter tracks the exact execution pointer in real-time.
* One-click code copy and customizable syntax theme.

---

### 3. 🔊 High-Fidelity Audio Sonification Engine
* Built with the native browser **Web Audio API**.
* Pitched sine and harmonic triangle waves represent element magnitudes (220 Hz – 1320 Hz).
* Specialized cues for swaps, comparisons, graph node visits, stack pops, and completion fanfares.
* Live 3-bar animated equalizer status pill in the header.

---

### 4. ⚔️ Real-Time Algorithm Duel & Benchmark Arena
* Pit any two algorithms head-to-head in real-time on identical datasets.
* Live counter metrics: Total Comparisons, Array Swaps/Writes, and Execution Time ($\mu s$).
* Compare quadratic algorithms ($O(n^2)$) vs logarithmic algorithms ($O(n \log n)$) visually.

---

### 5. 🎯 Deep Memory & Pointer HUD
* **Comparison Arcs**: Arcs display comparison predicates (`>`, `<`, `=`).
* **Bidirectional Swaps**: Kinetic particle arrows illustrate memory value exchanges.
* **Active Pointer Badges**: Real-time trackers for `i`, `j`, `mid`, `low`, `high`, `pivot`, `FRONT`, `REAR`, `HEAD`, and `TAIL`.
* **Live Variable Debugger**: Displays dynamic step states and memory allocations.

---

### 6. 🔐 Google One Tap & Google Sign-In Authentication
* Powered by official **Google Identity Services (GIS)**.
* **Google One Tap verification**: Instant one-tap sign-in prompt on page load without redirects.
* **Cloud Session Sync**: Synchronize learning progress, track mastered algorithms ($X/19$ checklist), and save personal algorithm bookmarks.
* **Instant Demo Mode**: Built-in fallback allowing developers and visitors to test all member features with zero setup.

---

### 7. 📱 Responsive, Mobile-First Interface
* Optimized for phones, tablets, and wide desktop displays.
* Touch momentum scrolling for node trains and memory arrays.
* 2-column dynamic mobile curriculum cards.
* Slide-out mobile drawer with instant brand navigation.

## 🚀 Getting Started

### Prerequisites
* **Node.js** (v18.0.0 or later)
* **npm** (v9.0.0 or later)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ratul-NotFound/AlgoViz.git
   cd AlgoViz
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **(Optional) Configure Google OAuth Client ID**:
   ```bash
   cp .env.example .env
   ```
   Add your Google OAuth 2.0 Client ID in `.env`:
   ```env
   VITE_GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
   ```
   *(If omitted, AlgoFlowX automatically operates in instant dev/demo mode!)*

4. **Start the local development server**:
   ```bash
   npm run dev
   ```

5. **Open in browser**:
   Navigate to [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

To generate the optimized production build:
```bash
npm run build
npm run preview
```
